# SECURITY POLICY

## Supported Versions

Only the current `main` branch is supported for security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅         |

## Reporting a Vulnerability

We take the security of APEX seriously. If you believe you have found a security vulnerability, please report it to us by [INSERT METHOD - e.g., opening a Private Vulnerability Report on GitHub].

**Do not open a public issue for security vulnerabilities.**

Once a report is received:
1. We will acknowledge receipt within 48 hours.
2. We will provide an estimated timeline for a fix.
3. We will coordinate a public disclosure date once the fix is ready.
